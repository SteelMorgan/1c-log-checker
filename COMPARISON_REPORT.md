### 2. Новые модули (internal/)

#### `internal/circuitbreaker/` - Circuit Breaker Pattern

**Файлы:**
- `circuit_breaker.go` - реализация circuit breaker
- `circuit_breaker_test.go` - тесты

**Назначение:** Защита от каскадных сбоев при проблемах с ClickHouse

**Что делает:**
- Отслеживает количество ошибок
- Автоматически открывает "цепь" при превышении лимита ошибок (по умолчанию 5)
- Переходит в half-open состояние через 30 секунд для тестирования
- Закрывает цепь после успешных операций

**Для чего:** Предотвращает перегрузку системы при недоступности ClickHouse, позволяет системе быстро восстанавливаться

**Использование:**
```go
cb := circuitbreaker.NewCircuitBreaker(5, 30*time.Second)
err := cb.Execute(ctx, func() error {
    return writer.WriteEventLog(ctx, record)
})
```

---

#### `internal/clickhouse/pool.go` - Connection Pooling

**Файлы:**
- `pool.go` - реализация пула соединений
- `pool_test.go` - тесты
- `client_test.go` - тесты клиента

**Назначение:** Управление пулом соединений к ClickHouse для повышения производительности

**Что делает:**
- Создает и управляет пулом соединений (min/max коннекции)
- Автоматически создает новые соединения при необходимости
- Возвращает соединения в пул после использования
- Предоставляет методы `Query`, `Exec`, `Execute`

**Для чего:** Устраняет узкое место с одной коннекцией, повышает производительность при высокой нагрузке

**Использование:**
```go
pool, err := clickhouse.NewPool(host, port, database, retryCfg, maxConns, minConns)
rows, err := pool.Query(ctx, "SELECT * FROM table")
```

#### `internal/health/` - Health Checks

**Файлы:**
- `health.go` - реализация health checker
- `health_test.go` - тесты

**Назначение:** Проверка состояния сервиса для мониторинга

**Что делает:**
- Проверяет соединение с ClickHouse
- Возвращает статусы: healthy/degraded/unhealthy
- Предоставляет HTTP handler для `/health` endpoint
- Кеширует результаты проверки (интервал 10 секунд)

**Для чего:** Позволяет оркестраторам (Kubernetes, Docker Swarm) проверять состояние сервиса

**Использование:**
```go
checker := health.NewChecker(chConn)
http.HandleFunc("/health", checker.HTTPHandler())
```

#### `internal/queue/` - Dead Letter Queue

**Файлы:**
- `dead_letter_queue.go` - реализация DLQ
- `dead_letter_queue_test.go` - тесты

**Назначение:** Хранение неуспешных записей для последующей обработки

**Что делает:**
- Сохраняет записи, которые не удалось записать в ClickHouse
- Раздельные файлы для event_log и tech_log (JSONL формат)
- Сохраняет контекст ошибки и количество попыток
- Thread-safe операции

**Для чего:** Позволяет не терять данные при временных сбоях, дает возможность повторной обработки

**Использование:**
```go
dlq, err := queue.NewDeadLetterQueue("/path/to/dlq")
dlq.AddEventLog(ctx, record, err, attempts)
```

---

#### `internal/ratelimit/` - Rate Limiting

**Файлы:**
- `rate_limiter.go` - реализация rate limiter
- `rate_limiter_test.go` - тесты

**Назначение:** Защита от перегрузки MCP endpoints

**Что делает:**
- Реализует token bucket алгоритм
- Ограничивает количество запросов (по умолчанию 100/сек, burst 20)
- HTTP middleware для применения к endpoints
- Автоматическая очистка неиспользуемых buckets

**Для чего:** Защищает систему от DDoS и перегрузки, обеспечивает fair usage

**Использование:**
```go
limiter := ratelimit.NewLimiter(100, 20)
http.Handle("/api/", limiter.HTTPMiddleware(handler))
```

---

#### `internal/logreader/eventlog/lgf_parser.go` - LGF Parser

**Файлы:**
- `lgf_parser.go` - парсер .lgf файлов

**Назначение:** Парсинг .lgf файлов (справочник объектов для event log)

**Что делает:**
- Парсит .lgf файлы (формат с фигурными скобками)
- Извлекает объекты: Users, Computers, Applications, Events, Metadata, Servers
- Поддерживает referenced objects (Users, Metadata с UUID)
- Thread-safe чтение с lazy loading

**Для чего:** Позволяет разрешать числовые идентификаторы в event log в читаемые имена

**Использование:**
```go
lgfReader := eventlog.NewLgfReader("/path/to/file.lgf")
userName := lgfReader.GetObjectValue(eventlog.ObjectTypeUsers, userNumber, ctx)
```

**Рекомендация:** Проверить конфигурацию и документацию
