## 🐛 Найденные и исправленные проблемы

### Критические (исправлены)

#### 1. Race condition в lastFlush
**Файл:** `internal/writer/clickhouse.go`  
**Проблема:** `lastFlush` обновлялся вне мьютекса  
**Исправление:** ✅ Обновление перенесено внутрь `batchMutex`

#### 2. Потенциальный deadlock при превышении maxBatchSize
**Файл:** `internal/writer/clickhouse.go`  
**Проблема:** Рекурсивный вызов `Flush` мог привести к deadlock  
**Исправление:** ✅ Используется прямой вызов `flush*Snapshot` вместо `Flush`

#### 3. Отсутствие таймаута при shutdown
**Файл:** `internal/service/parser_service.go`  
**Проблема:** Flush при shutdown мог зависнуть  
**Исправление:** ✅ Добавлен таймаут для flush при shutdown

---

### Важные (исправлены)

#### 4. Использование context.Background() вместо переданного контекста
**Файл:** `internal/service/parser_service.go`  
**Проблема:** Может привести к утечкам горутин  
**Статус:** ⚠️ Частично исправлено (для метрик используется Background с таймаутом, что допустимо)

#### 5. Отсутствие проверки на nil в метриках
**Файл:** `internal/service/parser_service.go`  
**Проблема:** Вызовы метрик могли паниковать

## 🔧 Исправления кода

### Исправление 1: lastFlush обновление
```go
// БЫЛО (race condition):
w.batchMutex.Unlock()
w.lastFlush = time.Now() // ❌ Вне мьютекса

// СТАЛО (thread-safe):
w.lastFlush = time.Now() // ✅ Внутри мьютекса
w.batchMutex.Unlock()
```

### Исправление 2: Предотвращение deadlock
```go
// БЫЛО (потенциальный deadlock):
if len(w.eventLogBatch) >= w.maxBatchSize {
    w.batchMutex.Unlock()
    w.Flush(ctx) // ❌ Может попытаться захватить мьютекс
    w.batchMutex.Lock()
}

// СТАЛО (без deadlock):
if len(w.eventLogBatch) >= w.maxBatchSize {
    batchSnapshot := make([]*domain.EventLogRecord, len(w.eventLogBatch))
    copy(batchSnapshot, w.eventLogBatch)
    w.eventLogBatch = w.eventLogBatch[:0]
    w.lastFlush = time.Now()
    w.batchMutex.Unlock()
    w.flushEventLogSnapshot(ctx, batchSnapshot) // ✅ Прямой вызов без мьютекса
    w.batchMutex.Lock()
}
```

### Исправление 3: Таймаут при shutdown
```go
// БЫЛО:
if err := s.writer.Flush(ctx); err != nil { // ❌ Может зависнуть

// СТАЛО:
flushCtx, flushCancel := context.WithTimeout(context.Background(), 10*time.Second)
if err := s.writer.Flush(flushCtx); err != nil { // ✅ С таймаутом
    log.Error().Err(err).Msg("Failed to flush writer during shutdown")
}
flushCancel()
```
